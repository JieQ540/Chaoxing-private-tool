# 超星学习通小助手 · 分享版 使用说明

> 版本：4.4.1-share.1 ｜ 适用：Tampermonkey / 脚本猫等用户脚本管理器
> **本脚本仅供学习研究，请遵守所在学校的学术规范，使用风险自负。**

---

## 一、它是什么

面向超星学习通（chaoxing.com）的用户脚本，功能：

- 章节视频 / 音频自动播放与进度上报
- 文档、PPT 自动阅读与时长计入
- 章节测验、作业、考试自动作答
- 闯关课程自动处理、进程守护（卡住自动刷新）
- **字体反爬解码**：新版作业页题目常以「叓/叒/収」这类占位字符存储，本版会自动还原成真字后再查题

**查题顺序**：一之免费题库 → 题库海付费题库 → DeepSeek AI 兜底。

---

## 二、安装

1. 浏览器安装 Tampermonkey 扩展；
2. 打开 Tampermonkey 面板 → 「添加新脚本」→ 全选删除模板内容 → 粘贴 `chaoxing-helper-share.user.js` 全文 → `Ctrl+S` 保存；
   （也可以把 `.user.js` 文件直接拖进浏览器窗口，Tampermonkey 会弹出安装页）
3. 打开任意 `chaoxing.com` 页面，左下角出现悬浮窗即安装成功。

---

## 三、必做配置（重要）

首次使用点悬浮窗里的「**配置**」按钮，在「其他配置」中填写：

| 配置项 | 必填性 | 说明 | 留空会怎样 |
| --- | --- | --- | --- |
| 一之题库token | 选填 | 向一之题库原作者申请的 token | 仍可查询，但可能受公共额度限制 |
| 付费题库token | 选填 | 题库海 `api.tikuhai.com` 的秘钥 | **自动跳过付费源**，不影响其他功能 |
| AI API Key | 选填 | DeepSeek 的 API key | **AI 兜底不启用** |
| 是否AI答题 | 选填 | 勾选后才启用 AI 兜底 | AI 不参与查题 |
| AI 接口地址 / 模型名 | 选填 | 默认 DeepSeek 官方地址与 `deepseek-chat`，可换任意 OpenAI 兼容网关 | 用默认值 |
| AI 单次上限 | 选填 | 单次运行最多问 AI 几题，默认 20 | 用于防止费用失控 |
| 调试日志 | 排错时开 | 打开后悬浮窗会输出 `[题库]/[付费]/[AI]/[解码]` 诊断 | 完全静默 |

**本脚本不含任何内置密钥**，也没有把答案上传到任何服务器的通道。

## 四、默认行为（请注意）

| 开关 | 默认 | 说明 |
| --- | --- | --- |
| 自动视频 / 文档 / 阅读 | 开 | 章节任务自动处理 |
| 自动答题 | 开 | 章节测验、作业、考试自动填写 |
| **自动提交** | **关** | 本分享版刻意默认关闭：答完请自己核对后再交 |
| 答案正确率 | 0.9 | 若你打开自动提交，答对率不足 90% 就不会提交 |
| 视频倍速 | 1 | 不建议调高，超星可能清理进度 |
| 是否AI答题 | 关 | 勾选且填了 AI key 才启用 |

## 五、常见问题

**Q：答不上来、显示「暂无答案」？**
按顺序排查：① 配置面板勾上「调试日志」；② 看悬浮窗里的日志：

| 日志 | 含义 | 怎么办 |
| --- | --- | --- |
| `未填付费题库token，已跳过付费源` | 没填付费 key | 填入题库海秘钥，或接受只用免费源 |
| `code:-1 未搜索到答案` | 题库里确实没有这道题（新题、时政题常见） | 靠 AI 兜底，或手动作答 |
| `请求超时` | 网络/跨域问题 | 检查网络与 Tampermonkey 的 `@connect` |
| `[AI] 已开启 AI 答题但未填 API Key` | AI 未配置 | 填 key 并勾选开关 |
| `[AI] 接口返回 status=401/402` | key 错误 / 余额不足 | 检查 DeepSeek 账户 |
| `[付费] 秘钥无效 / 剩余次数` | 付费 key 状态 | 按提示更换或充值 |

**Q：题目是乱码（叓、叒、収 这类字）？**
那是超星的字体反爬。本版已修复新版作业页的解码；若仍出现，请开「调试日志」把 `[解码]` 那行反馈。

**Q：视频播完不往下走？**
本版给视频任务加了异常兜底（原版遇到异常会静默卡死）。若仍卡住，开调试日志反馈。

**Q：AI 答案会错吗？**
会。AI 只作为题库查不到时的兜底，答案请自行判断——这也是本分享版默认关闭自动提交的原因。

**Q：成绩会受影响吗？**
本版默认不自动提交，答题内容需要你自己确认。请自行判断使用风险。

## 六、隐私说明

- 你填写的 token / key 只保存在本机 Tampermonkey 存储中，脚本**不会上传**它们；
- 启用对应源时，**题目内容**会发送给该源（一之题库 / 题库海 / DeepSeek），这是查题的必要条件；不同意可只开免费源、或关闭自动答题；
- 本脚本**不包含**把作业、试卷答案回传第三方服务器的通道，也不存在「由服务器返回数据驱动抓取页面」的行为（这两条是原始第三方版本里的问题，已在改造中移除）。

---

## 七、更新与卸载

- **更新**：Tampermonkey 面板 → 该脚本 → 编辑 → 覆盖粘贴新版本 → 保存。
  脚本未设置自动更新源，**不会被远程版本覆盖**你的修改。
- **卸载**：Tampermonkey 面板 → 删除该脚本。
- **重置配置**：在 Tampermonkey 的存储页（或脚本设置里）清除该脚本的存储数据即可。
